# HappinessAndInflationAnalysis
Inflation and happiness (data analysis)

Analysis including review and graphing of data on selected happiness indices worldwide.
The analyzed dataset contains information on related parameters for countries and continents in the context of the years 2015-2023.


Source dataset: https://www.kaggle.com/datasets/agrafintech/world-happiness-index-and-inflation-dataset
